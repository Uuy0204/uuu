# 七款游戏结算公式与计分规则

> 实际实现口径。以当前 `apps/server/src/games/` 的结算代码为准；本文同步于 2026-09-29。积分只用于娱乐，不对应现金或兑换价值。

## 三人斗地主

- 竞叫最高分成为初始倍率；农民选择加倍、炸弹或王炸、春天或反春均可使倍率翻倍，最高 256 倍。
- 令 `u = min(5, 四舍五入到 1 位小数(最终倍率 × 0.1))`。地主赢：地主 `+2u`，两农民各 `-u`；农民赢则全部反号。三人合计为零。
- 例如最终倍率为 12 时，`u = 1.2`，地主赢得 `+2.4`，两农民各 `-1.2`。文档旧例中的 `±24` 不适用于当前代码。

## 四人斗地主

- 两副牌，最高叫分作为初始倍率。炸弹和王炸使倍率翻倍，上限 256 倍。
- **混战：**按出完顺序排名，权重为 `+3 / 0 / -1 / -2`。令 `u = min(四舍五入到 1 位小数(倍率 × 0.1), 10/3)`，每人的积分为 `四舍五入到 1 位小数(u × 名次权重)`。第一名最多约 `+10`，四人合计为零。
- **对角组队：**首位出完者所在队获胜。令 `u = min(5, 四舍五入到 1 位小数(倍率 × 0.1))`，胜队两人各 `+u`，负队两人各 `-u`。

## 跑得快

- 三人局按出完先后取得基础分 `+0.2 / 0 / -0.2`；四人局为 `+0.3 / +0.1 / -0.1 / -0.3`。
- 每次四张炸弹使倍率翻倍，上限 256 倍；最终积分为基础分乘倍率并保留 1 位小数。合计为零。
- 当前实现没有“全关翻倍”或按赢家收取每位输家基础分的单局制。有牌可压时必须出牌。

## 争上游

- 三至四人使用整副 54 张牌，持黑桃 3 的玩家首出；可选择策略性过牌。
- 按出完名次结算：三人局基础分 `+0.2 / 0 / -0.2`，四人局 `+0.3 / +0.1 / -0.1 / -0.3`。四张炸弹倍率翻倍，最高 256 倍；王炸不另加倍。最终积分为基础分乘倍率并保留 1 位小数，合计为零。

## 小猫钓鱼

- 剩余不超过一位持牌玩家，或达到 1000 回合时结算。按每人**当前牌堆**的牌面累加：数字牌（包括 10）各 1 分，J/Q/K 各 3 分，A 5 分，小王 10 分，大王 15 分。
- 最高分者获胜；同分可并列。本玩法的结果为牌堆积分，**不是零和积分变化**。

## 德州扑克

- 每人以 1000 娱乐筹码开局；小盲 10、大盲 20，当前没有随局数递增的盲注表。
- 主池和边池按各玩家的累计投入拆分，仅有资格的玩家参与对应底池。完全相同牌力的赢家平分，不能整除的余数分给排序靠前的赢家。
- 每人的结算值为 `结束筹码 − 1000`；所有玩家结算值之和为零。

## 骗子酒馆

- 最后一名存活玩家获胜。若总人数为 `N`，赢家 `+0.1 × (N − 1)`，其余每人 `−0.1`；合计为零。
