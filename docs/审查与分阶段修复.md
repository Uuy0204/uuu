持久化配置：在 Render **服务端环境变量**设置 `UPSTASH_REDIS_REST_URL` 与 `UPSTASH_REDIS_REST_TOKEN`，不得放入 `NEXT_PUBLIC_` 或提交到仓库。先创建自己可长期管理的数据库；临时数据库会过期。免费额度、服务条款和存储上限以提供方当前页面为准。当前实现面向**单实例** Render 免费服务；存储故障时启动失败以免用空房间覆盖已有数据。运行中的写入异步排队，突发进程终止仍可能丢最后一次未完成的操作；多实例并发、身份令牌防冒用与严格事务持久化是后续安全工作。
